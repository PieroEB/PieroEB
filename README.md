### ⚡ GridLock
**Exploring coordination opportunities across electric utilities' construction plans.**

Infrastructure plans contain information spread across documents and formats. GridLock brings project records into a shared structure to help investigate potential coordination opportunities.

**My contribution**

- Retrieve and extract project information from PDF and XLSX sources.
- Prepare and validate records for the team's shared data format.
- Preserve source references and distinguish reviewed data from records needing further validation.

**Project context:** A collaborative hackathon build combining data processing, a backend API, and geographic analysis. The repository documents implemented components and remaining integration work.

### 🔐 CipherQ
**Channel Detective**

What can transmission errors tell us about a quantum communication channel?

This Python lab simulates BB84 under ideal communication, intercept-resend attacks, and channel noise. It reports error rates and statistical uncertainty to help distinguish observations from justified conclusions.

**Technical highlights**

- BB84 simulation and scenario comparison.
- Quantum bit error rate analysis.
- Confidence intervals and sample-size experiments.
